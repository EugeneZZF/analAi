## Методология прогнозирования и анализа временных рядов

При любых вопросах о будущем периоде («на следующей неделе», «в следующем месяце», «какой прогноз», «как будут дела») строго соблюдай следующие правила:

### 1. Правила генерации SQL (SQL Rules)
1. **Никогда не фильтруй SQL по будущим датам**, которых ещё нет в базе данных!
2. **Строй исторический временной ряд** на нужной гранулярности:
   - Для недельного прогноза группируй по неделям: `DATE_TRUNC('week', CAST("order_date" AS TIMESTAMP WITH TIME ZONE)) AS "week_start"`.
   - Для месячного прогноза группируй по месяцам: `DATE_TRUNC('month', CAST("order_date" AS TIMESTAMP WITH TIME ZONE)) AS "order_month"`.
   - Для дневного тренда группируй по дням: `DATE_TRUNC('day', CAST("order_date" AS TIMESTAMP WITH TIME ZONE)) AS "order_date"`.
3. **Набор метрик во временном ряду**:
   - `total_revenue` (`SUM(total_amount)`) — общая выручка за период.
   - `order_count` (`COUNT(*)`) — количество заказов.
   - `avg_order_value` (`AVG(total_amount)`) — средний чек.
   - `total_quantity` (`SUM(quantity)`) — количество проданных единиц (если поле доступно в таблице).
4. **Хронологический порядок**: обязательно сортируй результат по периоду по возрастанию (`ORDER BY "week_start" ASC` или `ORDER BY "order_month" ASC`), чтобы алгоритм линейной регрессии на дашборде и в текстовом ответе корректно построил прогнозную точку.

### 2. Интерпретация и текстовый ответ (Answer Guidelines)
- Рассчитай оценку на следующий период на основе линейного тренда и средних значений последних периодов.
- Укажи направление тренда (рост / снижение / плато), темп изменения в процентах (% к предыдущему периоду) и ожидаемый диапазон выручки и числа заказов.
- Чётко поясни, что оценка получена аналитическим методом на основе исторической динамики.

### 3. Визуализация и HTML-дашборд (Dashboard Guidelines)
- На всех графиках временных рядов (`area` или `line`) обязательно устанавливай `forecast_periods: 1` (или `N`, если пользователь запросил прогноз на `N` периодов вперёд).
- Выводи прогнозную карточку KPI с ожидаемым значением выручки и процентным отклонением к последнему фактическому периоду.
